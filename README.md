## 📌 Sobre o projeto

O **GeoFire** é um projeto desenvolvido com o objetivo de praticar desenvolvimento web, tratamento de dados e visualização de informações relacionadas a incêndios.

A aplicação utiliza dados armazenados em um arquivo CSV e apresenta as informações de forma organizada, permitindo consultar os registros e realizar filtros por estado.

O projeto também faz parte do meu processo de aprendizado em **análise de dados, programação e geotecnologias**.

---

## 🎯 Objetivos

- Trabalhar com dados reais armazenados em CSV;
- Praticar tratamento e organização de dados;
- Desenvolver filtros para consulta dos registros;
- Criar indicadores a partir dos dados;
- Desenvolver uma interface para visualização das informações;
- Aplicar conhecimentos de HTML, CSS e JavaScript;
- Evoluir futuramente o projeto para análises gráficas e geográficas.

## 📊 Funcionalidades atuais

Atualmente, o GeoFire possui:

- 🔥 Cálculo do total de ocorrências;
- 📍 Identificação do estado com maior quantidade de ocorrências;
- 📊 Cálculo da média de ocorrências;
- 📋 Tabela com os registros dos incêndios;
- 🔎 Filtro por estado;
- 🔄 Atualização dos indicadores de acordo com o estado selecionado;
- 📁 Leitura dos dados diretamente de um arquivo CSV.
