SOBRE O PROJETO

Tecnologia a favor do monitoramento ambiental

O GeoFire é um projeto desenvolvido para estudar programação, tratamento de dados e visualização de informações relacionadas a incêndios e queimadas.

O projeto utiliza dados em formato CSV e JavaScript para transformar registros em informações que podem ser consultadas de forma simples e organizada.
